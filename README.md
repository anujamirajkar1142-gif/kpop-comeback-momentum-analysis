#  K-Pop Comeback Momentum Analysis 

## Project Overview

The K-Pop industry is highly dynamic, with songs frequently re-entering music charts after promotions, viral trends, fan campaigns, social media activity, and comeback events.

This project analyzes chart re-entry patterns, fandom intensity, and momentum spikes using South Korea's Top 50 music chart data.

An interactive dashboard was developed using Streamlit to help record labels identify songs with strong comeback potential and understand audience engagement patterns.

---

##  Objectives

- Analyze chart re-entry behavior
- Measure fandom intensity
- Detect momentum spikes
- Identify artist and album performance patterns
- Visualize comeback trends using an interactive dashboard

## Dashboard Features

### Key Performance Indicators (KPIs)

- Total Songs
- Total Artists
- Re-entry Events
- Average Momentum Spike
- Average Re-entry Frequency
- Average Retention Period
- Album Advantage Index
- Average Fandom Intensity

### Interactive Filters

- Date Range
- Song Filter
- Artist Filter
- Album Type Filter
- Minimum Re-entry Filter
- Minimum Days Outside Chart Filter

### Visualizations

- Re-entry Timeline
- Momentum Distribution
- Artist Performance Analysis
- Album Type Comparison
- Fandom Intensity Analysis
- Chart Retention Patterns

---

## Key Insights

- Several songs re-entered the charts multiple times.
- Strong fandom activity significantly influenced chart re-entry.
- Momentum spikes were closely associated with comeback events.
- Album type affected retention and re-entry behavior.
- Certain artists consistently demonstrated stronger comeback momentum.
